# Voklaris

Gotowa strona portfolio. Wygląda tak samo jak podgląd: ciemne tło, logo, portret, karty projektów, filtr kategorii, umiejętności, formularz i stopka.

To nie jest projekt do budowania. Nie uruchamiaj `npm`. Opublikuj te pliki tak, jak leżą.

Na GitHub Pages: wgraj zawartość tego katalogu do gałęzi `main` (plik `index.html` ma być w korzeniu repozytorium) i włącz Pages z folderu głównego.

Lokalnie wystarczy otworzyć `index.html`.
